# Capítulo 01 — Fundamentos básicos

Este capítulo apresenta os fundamentos de Python usados em todo o curso.

## print()
- `print()` exibe texto e valores no terminal.
- É a forma mais simples de ver resultados enquanto se aprende.

## Comentários
- Comentários começam com `#`.
- Servem para explicar o código e não são executados.

## Variáveis
- Armazenam valores com `nome = valor`.
- Não é preciso declarar o tipo.
- Exemplos: `idade = 18`, `nome = 'Ana'`, `ativo = True`.

## Tipos básicos
- `int`: números inteiros, como `5`.
- `float`: números com casa decimal, como `3.14`.
- `str`: cadeia de caracteres, ou texto.
- `bool`: valores booleanos `True` e `False`.

## Entrada de dados
- `input()` lê texto do usuário.
- O valor lido é sempre `str`.
- Converta para `int()` ou `float()` quando precisar de números.

## Operadores aritméticos
- `+` soma, `-` subtrai, `*` multiplica, `/` divide.
- `//` divisão inteira, `%` resto, `**` potência.

## Comparações e booleanos
- `==` igual, `!=` diferente.
- `>` maior, `<` menor.
- `>=` maior ou igual, `<=` menor ou igual.
- Essas comparações retornam `True` ou `False`.

## Condicionais básicas
- `if` executa um bloco quando a condição é verdadeira.
- `else` executa quando a condição é falsa.

## Laços básicos
- `for` repete uma ação para cada item de uma sequência.
- `while` repete enquanto a condição for verdadeira.
