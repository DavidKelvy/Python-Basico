# 📚 Sobre o Projeto

Este projeto transforma o conteúdo do livro **Python Crash Course (3rd Edition)** em uma aula organizada

O material aborda desde:
- fundamentos da linguagem Python;
- estruturas de dados;
- programação orientada a objetos;
- manipulação de arquivos;
- testes;
- visualização de dados;
- desenvolvimento web com Django;
- até criação de jogos com Pygame.
