# Capítulo 05 — Condicionais

Conceitos abordados:

- **`if`, `elif`, `else`**: estruturas de decisão para executar blocos condicionalmente.
- **operadores de comparação**: `==`, `!=`, `>`, `<`, `>=`, `<=`.
- **operadores lógicos**: `and`, `or`, `not` para combinar condições.
- **teste de pertinência**: `in` / `not in` para verificar se elemento está em coleção.
- **valores truthy/falsy**: objetos vazios, `0`, `None` são falsos em condições.
- **validação e fluxos de negócio**: padrão comum para checar permissões ou pré-condições.

As condicionais dirigem o fluxo do programa com base em estados e entradas.
